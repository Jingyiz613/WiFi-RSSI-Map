# 剔除两组存疑数据后的重新训练与评估

## 主要结果

按用户要求，本轮建模数据完全剔除两个CSI/NPZ数据包：P49（20261020_195100）和P26（20261020_202128）。原始压缩包和以往成果没有删除或改动。

剩余 **8组、495个实测位置标签**，重新按约7:2:1取整为 **6/1/1**：

- 训练：P16、P22、P28、P44、P64、P68；372个标签。
- 验证：P62；61个标签。
- 测试：P74；62个标签。

三个网络各重新训练3个随机种子，共9次；标准化只用本轮6组训练数据重新拟合。路径损耗系数和两种GPR核参数也仅用本轮保留的训练/验证数据重新选择。核搜索范围、网络架构、预算、优化设置均沿用原方案，没有根据本轮测试误差追加调参。统计方法使用相同固定掩码。

代表性条件“P74，12个均匀输入点，预测50个隐藏实测点，10个固定掩码”下：

| 模型 | MAE(dB) | RMSE(dB) | R² | ≤5dB比例 | 对IDW的RMSE改善 |
|---|---:|---:|---:|---:|---:|
| IDW | 4.259 | 5.434 | 0.085 | 64.2% | 0.00% |
| 普通GPR | 4.143 | 5.340 | 0.116 | 66.0% | 1.73% |
| 纯路径损耗 | 3.566 | 4.379 | 0.406 | 76.8% | 19.41% |
| 路径损耗＋GPR | 3.563 | 4.356 | 0.412 | 75.4% | 19.83% |
| 卷积自编码器 | 4.562 | 5.939 ± 0.219 | -0.094 | 63.5% | -9.30% |
| 小型U-Net | 4.731 | 6.112 ± 0.071 | -0.158 | 62.3% | -12.48% |
| 残差U-Net | 4.313 | 5.483 ± 0.006 | 0.068 | 65.7% | -0.90% |

路径损耗＋GPR的RMSE比同一条件IDW降低 **19.83%**。纯路径损耗已接近这一结果；GP残差的额外改善为 **0.0231 dB**，收益有限。三个网络在这个条件下的RMSE仍未优于IDW。误差≤5dB比例上，纯路径损耗为76.8%，略高于路径损耗＋GPR的75.4%；因此不存在所有指标统一最优的说法。

## 选择原则与结论边界

按P62验证集上全部预算/分布的总体RMSE，选中 **路径损耗＋GPR**，不是根据P74结果改选。各方法验证总体RMSE如下：

| 方法 | P62验证总体RMSE(dB) |
|---|---:|
| IDW | 6.911 |
| 普通GPR | 6.918 |
| 纯路径损耗 | 6.266 |
| 路径损耗＋GPR | 6.068 |
| 卷积自编码器 | 6.546 |
| 小型U-Net | 6.339 |
| 残差U-Net | 6.670 |

**本轮P74以前参与过验证，因此属于探索性重新划分，并不是新的盲测。** 旧实验测试组是P49，新实验测试组是P74；它们场景不同，不能把两个数字直接相减，归因于剔除存疑数据。当前结果只能说明：完全不用这两组数据后，在这次固定划分和输入协议下，保留数据得到上述表现；不能证明那两组数据一定错误或一定造成过拟合。

只有1张验证地图和1张测试地图，选模可能对部署敏感。训练组只有6张独立地图，重复采样掩码不会增加独立场景数。此实验不证明跨房间能力，也没有增加新的独立数据。

## 数据完整性

两个存疑部署的标签、CSI包和旧模型权重都没有进入本轮训练、标准化或核参数拟合。保留的8张地图数据在 `neural/data/maps.npz` 与 `gpr/data/maps.npz` 中，已显式验证没有P26/P49。

P62沿用用户确认的实际AP位置P62，原程序误记的P11保持缺测，没有使用手工−40dBm。它的P22仅5次、P21仅9次有效读数，其余失败记录不作为0值。P62作为验证组只有61个有效位置。各轮高度/朝向记录缺失等原有局限仍存在。

两类新方法用的标签均为HTTP Wi-Fi RSSI点中位数，已没有被剔除两包的CSI逐帧RSSI混入。所有方法的IDW基线与原实验保留地图的相同掩码预测一致。GP后验与神经网络都只以本次提供的观察点作为输入，隐藏点只用于监督或评估。

## 方法与可比性

- 网络：原三通道卷积补全自编码器、小型U-Net、四通道IDW残差U-Net，8/16/32通道；AdamW、lr=0.001、batch=24、最多180epoch、验证早停，随机种子20261021/22/23不变。全部重新拟合，不复用此前混合数据训练的权重。
- GPR：普通常数均值GPR与路径损耗均值GPR，Matérn1.5/2.5；每家族96组核参数由6个训练组REML筛选，再由P62验证集选参数。纯路径损耗为训练组拟合距离衰减斜率、本次输入点估计局部截距。
- 路径损耗类方法额外使用已知AP坐标，IDW/普通GPR/原三通道网络不使用AP坐标。这也是物理先验带来的信息优势，不能将全部收益归结为GPR结构。
- 6/12/24个输入点，均匀随机/局部聚集，每条件10个固定掩码；误差仅计算隐藏实测位置。网络取3种子均值，±为种子标准差；非网络方法不重复伪造训练种子。
- 12点条件下10×50=500次预测并非500个独立位置或场景。R²、P90、Bias、≤3/5dB比例和全预算结果见CSV。

## 交付与复现

- `metrics_summary.csv`：七种方法在验证/测试、全部预算和分布上的统一指标。
- `metrics_overall.csv`：各分区合并预算的总体误差。
- `neural/`：9份新训练权重、结构/训练/评估/推理代码、曲线、标准化、固定掩码和逐种子指标。
- `gpr/`：四种新模型JSON、核搜索记录、路径损耗拟合、逐掩码指标和推理代码。
- `figures/`：全部方法误差曲线、训练验证曲线、固定第0号P74掩码的地图比较。
- `verification.json`：两类模型在新进程仅读取稀疏输入与模型参数的重载验证，以及剔除组和标准化范围检查。

同一稀疏输入推理示例：

```powershell
python gpr/code/infer.py --model gpr/models/pathloss_gpr.json --points demo_inputs.csv --ap P74 --output new_map.csv
```

神经网络示例（权重按 `neural/selection.json` 选择）：

```powershell
python neural/code/infer.py --checkpoint neural/models/unet_20261021.pt --points demo_inputs.csv --output new_neural_map.csv
```

`demo_inputs.csv`只有12个真实观察值；推理程序不读取参考标签。输出为63格，输入格原值保留，其他格为预测，包括没有实测监督的AP格，不代表每格都已验证准确。GPR输出的区间包含噪声与局部截距不确定性，不应当作已经校准的覆盖保障。

复现网络：`python neural/code/train.py` 后 `python neural/code/evaluate.py`；复现GP：`python gpr/code/run_experiment.py`。安装依赖见根目录 `requirements.txt`，包含CPU版PyTorch所需索引。先复制工作目录，复现会更新当前结果。
