# 九组 RSSI 数据表 v1

主文件 training_points.csv：557 个可用实测点，一行代表一个部署中的一个测点；RSSI 单位 dBm，坐标单位米。
AP_Pxx.csv：九组各自的可用数据；scene_manifest.csv：场景清单与来源哈希；audit_all_grid_points.csv：全部 567 个网格位置（包括不可用点）；quality_issues.csv：特殊记录。

## 分组
训练：P22、P68、P44、P28、P62、P16；验证：P64；最终测试：P49、P26。属于第一版建议划分。包内逐点 train/test 标签未采用，不代表已固定网络输入点。

## 字段与规则
- rssi_median_dbm 为模型目标；eligible=1 才可用于输入或监督，0 不可用。缺值为空，绝不当作 0 dBm。
- 坐标按西南角原点、x 向东、y 向北，使用统一网格中心精确计算；原文件不变。
- P62 按用户确认修正实际部署；剔除路由器占用 P62 的 10 条记录，P11 的试测替代 -40 仅记在审计表 trial_substitute_dbm，不进入模型数据。该轮可用 61 点。
- P62 的 P22 有效读数 5 次、P21 有效读数 9 次，保留已有中位数并标 partial_measured；不补造读数。
- 其余八组各 62 点。P49、P26 使用 points_features.csv 中设备 RSSI 中位数；NPZ 原始数组尚未重算核验。
- P49、P26 的逐包 RSSI 与前七组的接口轮询采样方式不同；测试结果同时反映采集方式差异与部署差异。标准差的计算口径也不保证完全一致，第一版模型先仅用中位数。
- 高度未记录，不猜测。没有生成插值真值、标准化参数、输入点抽样或模型权重。
- split 为场景级划分；标准化只允许由训练场景计算。最终测试不用于调参。

已校验：九个来源各 62 个不重复点；输出坐标、缺值、有限数值、特殊点排除及总行数。未声称对所有原始数组和历史采样做重新校准。
