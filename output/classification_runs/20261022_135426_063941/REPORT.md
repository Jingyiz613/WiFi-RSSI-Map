# 五档分类实验

分档为本项目相对信号强弱，非通用Wi-Fi可用性或网速标准。根据训练数据范围固定，没有按测试成绩选阈值。

|类别|范围 dBm|七组训练点数|
|---|---|---:|
|弱|小于 -40|60|
|较弱|-40 ≤ RSSI < -35|126|
|中|-35 ≤ RSSI < -30|136|
|较强|-30 ≤ RSSI < -25|74|
|强|大于等于 -25|37|

网络直接输出五类概率和类别，没有RSSI回归输出；距离估算图仅为输入特征。损失为加权交叉熵，仅隐藏实测点参与，权重仅由训练类频数决定。
7组训练：P16, P22, P28, P44, P62, P68, P74；P64固定10组20点输入，隐藏42点。标准化仅来自训练数据。P49/P26未评分。

|方法|准确率|五类宏平均F1|相差不超过一档|平均错档数|
|---|---:|---:|---:|---:|
|五档分类网络|42.6%|0.341|72.4%|0.883|
|距离估算后按同一阈值分档|42.1%|0.250|87.6%|0.705|

最佳第24轮，运行64轮。按验证集五类宏平均F1选权重。
准确率只指预测类别正确，不等于RSSI数值更准确；五档任务与此前回归任务指标不能直接比较。
重复选点不是独立场景；P64已反复用于模型选择，结果仅为验证，不能声称新独立测试或跨房间效果。空房间使距离估算有竞争力是合理假设，尚未单独验证因果。
低于阈值到边界的细小变化可改变一档。置信概率未经过校准，不能视为真实正确率。原有回归实验未替换或删除。
