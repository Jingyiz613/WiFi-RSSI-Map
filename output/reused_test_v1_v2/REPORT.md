# 两版残差网络：验证与重复测试比较

更新时间：2026-10-21。指标均来自已保存的实际运行结果；本次仅汇总，没有重新训练或评分。

## 方法与实验规则

- 普通距离估算（idw）：仅用本次20个输入点做距离平方反比加权估算。无需训练。
- 第一版残差网络（residual_v1）：距离估算加网络修正，训练使用 P16、P22、P28、P44、P62、P68。
- 第二版残差网络（residual_v2）：同类网络，训练增加 P74，共七组。
- 两版均用 P64 选择最佳权重。每个检查场景有10组固定20点输入，其余42个实测点用于计算误差；所有方法在同一场景使用相同输入点。
- 第一版残差模型最佳为第1轮，第二版为第25轮。此处第一版指残差模型，并非先前直接预测的小型U-Net。

## 如何解读

第二版在验证集P64上略好，但在重复测试的P49、P26上均更差，说明这次验证改善没有稳定延续到这两个部署。不能认为第二版总体更好，也不能仅凭一次实验断定增加数据必然有害。
不将P64与P49/P26合算为一个总分，因为验证集参与了模型选择，角色不同。
MAE是误差绝对值的平均数；RMSE是误差平方的平均数再开方，更重视大错误。两者越小越好，单位dB；RSSI本身单位为dBm。
每场景420条评分对应42个隐藏点乘10次不同选点，仍只有62个实测位置，不是420个独立测点。

## 数据分配与限制

- 训练：第一版六组371个可用点，第二版七组433个可用点。训练时每场景随机给出20个点，只在其余有效实测点计算损失并更新参数。
- 验证：P64；固定10组输入点，验证计算不更新参数，但结果影响最佳权重选择与方案调整。
- 测试：P49、P26；第一版初次最后评估后已被查看，第二版再次使用只作为重复对照。
- 后两组采样方式与训练集不同，部署位置和采样方式的影响无法单独分离。仅覆盖同一房间两个测试部署，不能推广到其他房间。
- P62按用户确认修正部署标注，路由器占位点及无原始读数的P11替代值未作为训练目标。
- 模型路径、哈希及重复测试输入点见 frozen_plan.json；原始结果保留在各训练目录及本目录 summary.json。
