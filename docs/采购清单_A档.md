# A 档采购清单（淘宝直达搜索链接 + 选型标准）

> 用法：点链接 → 按「选型标准」挑第一家符合的 → 全部加购物车一次下单。
> 统一技巧：搜索词后加「顺丰」或下单时筛「顺丰包邮」，D3 前到货。

## ① 差速底盘（核心件，别买错）

- 链接：https://s.taobao.com/search?q=双层亚克力智能小车底盘套件+编码器电机+顺丰
- 备选词：「智能小车底盘 520编码电机 套装」
- 选型标准：
  - 必须写 **「编码器电机」或「带码盘」**（纯 TT 马达没有编码器，不能要）
  - 电机型号 **520 或 370**，电压 6~12V
  - 轮径 **≥65mm**，带 **万向轮**（差速转向全靠它）
  - 双层亚克力车架（上层放主控、采集板支架）
- 价格带：¥100~150；月销 100+ 的店随便选
- 避坑：「四驱/4WD」不要（不好转向）；「履带底盘」不要（室内转向伤地板且漂移大）

## ② 运动主控

- 链接：https://s.taobao.com/search?q=ESP32+DevKit+V1+开发板+顺丰
- 选型标准：**ESP32-WROOM-32**（双核，38pin 或 30pin 都行）；Micro-USB 或 Type-C 随意
- 价格带：¥20~30
- 避坑：别买成 ESP32-C3/S3（引脚定义不同，教程不通用）；认准「ESP32 DevKit V1」
- 备注：这是运动主控，和你的 ESP32-C6 采集板是两块板子，别搞混

## ③ 陀螺仪

- 链接：https://s.taobao.com/search?q=MPU6050+陀螺仪+加速度计+模块+顺丰
- 选型标准：GY-521 板型，I2C 接口，带排针（已焊好或送排针自焊都行）
- 价格带：¥6~12

## ④ 超声波 ×3

- 链接：https://s.taobao.com/search?q=HC-SR04+超声波+测距+模块+顺丰
- 选型标准：就一种标准件，买 3 个（左/右贴墙纠偏 + 前方避障）；多数店 2~3 元一个
- 价格带：3 个 ¥10~18
- 避坑：别买成 US-100（串口协议不同）；电压 5V 版

## ⑤ 电机驱动

- 链接：https://s.taobao.com/search?q=TB6612FNG+电机驱动+模块+顺丰
- 选型标准：TB6612 双路驱动小板（红色或黑色 PCB 都行），能驱 2 个直流电机
- 价格带：¥8~15
- 避坑：别买 L298N（体积大、发热大、压降高，7.4V 电池被吃掉 2V）

## ⑥ 车电（18650×2 + 降压）

- 电池盒：https://s.taobao.com/search?q=18650+电池盒+2节+带开关+带线+顺丰
  - 标准：**2 节串联（7.4V）、带开关、带引出线**；¥5~10
- 电池：https://s.taobao.com/search?q=18650+充电电池+平头+2节+顺丰
  - 标准：容量 2000mAh+，**平头**（尖头可能顶不到电池盒弹片）；2 节 ¥20~30
  - 顺手买：搜「18650 充电器 双槽」¥10（家里没有的话）
- 降压：https://s.taobao.com/search?q=LM2596+降压+模块+可调+顺丰
  - 标准：可调输出（调到 5V 给主控和传感器供电）；¥3~8

## ⑦ 结构杂件

- 杜邦线：https://s.taobao.com/search?q=杜邦线+公对公+母对母+公对母+套装
  - 标准：三种各一排的套装，20cm；¥8~12
- 铜柱：https://s.taobao.com/search?q=M3+铜柱+双通+六角+套装
  - 标准：M3×10+6 双通为主的小套装；¥8~10
- 采集板支架：https://s.taobao.com/search?q=亚克力+展示架+可调+或+支架+杆
  - 灵活处理：相机小三脚架、手机支架杆、亚克力板+铜柱自搭都行；目标 **0.8~1.0m 可调、顶部平台能绑住采集板、不晃**；¥20~40
  - 替代词：「桌面 支架 伸缩 杆」「亚克力板 定制 打孔」

## 不需要买的

- 采集板充电宝：用你现有的（采集板独立供电，与车电分离）
- 烙铁：如果完全不想焊接，买件时全部选「已焊排针」选项

## 下单前自检

| 检查项 | 标准 |
|---|---|
| 底盘电机 | 有编码器/码盘字样 ✅ |
| 超声波数量 | ≥3 ✅ |
| 主控型号 | ESP32 DevKit V1（非 C3/S3）✅ |
| 电池 | 平头 18650 ×2 + 有充电器 ✅ |
| 运费 | 全部顺丰，合计 ≤¥500 ✅ |
